# Onco-Target-Explorer

Скачай `onco-target-explorer.zip`, распакуй в любую папку и запусти `START.bat`
(двойной клик) из распакованной папки.

## Что нужно на компьютере
- Windows
- Miniconda или Anaconda, установленная с галочкой **"Add to PATH"**
  (скачать: https://www.anaconda.com/download)
- Интернет — **только при самом первом запуске** (ставит python-пакеты в
  окружение `molgen`). Дальше всё работает офлайн.

## Что делает START.bat
1. Находит conda, создаёт окружение `molgen` (один раз).
2. Проверяет видеокарту/драйвер NVIDIA (для gnina CNN-рескоринга — не
   обязательно для основного докинга).
3. Проверяет офлайн-готовность данных мишеней.
4. Запускает очередь докинга (Vina) по всем мишеням, прошедшим гейт.
   Прогресс сохраняется на диск после каждого лиганда — окно можно
   закрывать и открывать заново, ничего не передокуется повторно.

Если что-то пойдёт не так — открой `SETUP_NEW_MACHINE.md` внутри zip,
там подробности по WSL2/gnina/fpocket (опциональная CNN-часть).
