# Onco-Target-Explorer

Скачай **[onco-target-explorer.zip](https://github.com/adilhanzheksengaliev2006-alt/onkohuy/releases/download/v1.0-launcher/onco-target-explorer.zip)**,
распакуй в любую папку и запусти `START.bat` (двойной клик) из распакованной папки.

## Что нужно на компьютере
- Windows
- Miniconda или Anaconda, установленная с галочкой **"Add to PATH"**
  (скачать: https://www.anaconda.com/download)
- Интернет — **только при самом первом запуске** (ставит python-пакеты в
  окружение `molgen`). Дальше всё работает офлайн.

## Что делает START.bat
1. Находит conda, создаёт окружение `molgen` (один раз).
2. Проверяет видеокарту/драйвер NVIDIA (для gnina CNN-рескоринга — не
   обязательно для основного докинга).
3. Проверяет офлайн-готовность данных мишеней.
4. Запускает очередь докинга (Vina) по всем мишеням, прошедшим гейт.
   Прогресс сохраняется на диск после каждого лиганда — окно можно
   закрывать и открывать заново, ничего не передокуется повторно.
5. Как только докинг для мишени полностью завершён (все лиганды, не
   после каждого прерывания) — автоматически запускает по ней
   `controls/run_controls.py --stage all`: тесты 1-4, 7, 9-15, 17 и
   сводный тест 18 (главный вывод, пересчитывается заново по мере того,
   как появляются новые законченные мишени).
6. Следом автоматически запускает **Test 6** (cross-docking) для мишеней
   из 11 боевых, для которых заранее найдены альтернативные PDB-записи
   (`alt_structures_for_test06.json`, собран `find_alt_structures.py` —
   автопоиск через RCSB, вручную список составлять не нужно).

Тесты 8 и 16 в автозапуск НЕ входят — не из-за мощности машины, а по
инфраструктурным причинам: Test 8 нужен fpocket из WSL2 (для установки
WSL2 нужны права администратора — без них не поставить в принципе), а
Test 16 требует отдельного генеративного прогона DiffSBDD (Test B),
который тут не запускается. Если понадобятся — запускаются вручную
отдельно (Test 8 — на машине с админ-правами и WSL2).

Если что-то пойдёт не так — открой `SETUP_NEW_MACHINE.md` внутри zip,
там подробности по WSL2/gnina/fpocket (опциональная CNN-часть).

## Что реально в очереди (на 09.09.2026)

Докинг (Stage 3) запустится для **45 мишеней, ~107 000 лигандов**:
8 из 11 "боевых" (PIK3CA, ESR1, AR, CDK2, BRAF, EGFR, ABL1, PARP1 — CA2,
HDAC2, PPARG не прошли Stage 1 redock-гейт, это легитимный отсев по
протоколу) + 37 auto-discovered мишеней для Test 18 (из 90 возможных —
у остальных либо гейт не пройден, либо технический сбой подготовки
рецептора, см. `runs/_onboard_progress.json`).

По измеренной скорости (~120 сек/лиганд с gnina) полный прогон займёт
от нескольких дней до нескольких недель в зависимости от числа ядер
машины — процесс resume-safe, можно дробить на сессии.
